\## ✨ Features

\- 🔐 User Authentication (Signup/Login with JWT)

\- 📝 Log Sleep Sessions (bed time, wake time, quality 1-5)

\- 🏷️ Factor Tracking (Caffeine, Exercise, Screen Time)

\- 📊 Analytics Dashboard (avg duration, best/worst nights)

\- 🎯 Sleep Goals (target bed/wake time)

\- 🤖 AI-Powered Recommendations

\- 🎨 Modern Classic UI Design



\## 🛠 Tech Stack

\- \*\*Frontend:\*\* React.js 18

\- \*\*Backend:\*\* Python Flask

\- \*\*Database:\*\* SQLite

\- \*\*Auth:\*\* JWT Tokens
